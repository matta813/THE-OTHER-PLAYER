# Game Design

The current slice establishes believable cooperation: a short terminal exchange, delayed remote unlock, a simple power request, and acknowledgement. Dialogue is deliberately terse. Fear is limited to uncertainty, inaccessible-space lighting, environmental contrast, and the sense that cooperation is being observed.

The first learned-habit manipulation is conditional: repeated checks of the first locked door can cause the Other Player to illuminate Room B before the player restores power. It reads as attentive teamwork and does not reveal the premise. A separate expectation test delays the final acknowledgement after earlier reliable replies. During that silence, terminal revisits are observed; sufficient estimated suspicion can bring a quicker, plausible reassurance. The systems have only one opportunity for each event in this small slice, so long-term psychological escalation remains untested.
