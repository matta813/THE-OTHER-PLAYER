# Other Player System

The Other Player is an invisible runtime agent with current task, scheduled actions, memory, confidence, and simulated activity. Reaction delay combines task complexity, player hesitation, confidence, and deterministic context variation; simple door control is faster than implied remote work. It operates facility objects exclusively through stable-ID remote APIs.

The current memory stores help count, last response time, and whether anticipatory lighting occurred. Predictions carry type, target, confidence, issue time, expiry, and result, with aggregate accuracy. This is heuristic and intentionally limited—not an LLM and not omniscient.
