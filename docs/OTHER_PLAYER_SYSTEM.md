# Other Player System

The Other Player is an invisible runtime agent with current task, scheduled actions, memory, confidence, and simulated activity. Reaction delay combines task complexity, player hesitation, confidence, and deterministic context variation; simple door control is faster than implied remote work. Due actions execute in timestamp order even if several become due in one frame, and the scheduler sleeps while idle. It operates facility objects exclusively through stable-ID remote APIs.

Short-term task memory stores help count, last response time, and whether anticipatory lighting occurred; structured habit memory lives in `BehaviourMemory`. `TrustStrategy` separately counts reliable/helpful acts, raises player trust through actual help, forms expectations, and can record reassurance. The agent can add context-triggered hesitation and a short "sec" message when the player repeatedly tests the locked door. Terminal text reveals only the latest line at a variable, restrained typewriter cadence.

Predictions now use habit confidence when available and carry source, debug-only reason, issue/expiry/window, actual outcome, and aggregate accuracy. A meaningful alternative action resolves a prediction as incorrect; silence can expire it. Adaptive decisions are scored, not random, and debug counterfactuals show the selected candidate and alternatives. The model is intentionally limited—not an LLM, and not omniscient.
