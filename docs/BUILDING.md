# Building
Godot 4.3+ on Linux is required. Run with `./tools/run.sh`, import/runtime-check with `./tools/check.sh`, and run logic, collision/vertical-flow, adaptive-scenario and chapter-path tests with `./tools/test.sh`. The renderer is configured for Forward+; headless validation uses a dummy renderer and cannot judge lighting or camera-feed appearance. For visual QA, run with Vulkan Forward+ and inspect the Security, Generator and Airlock spaces as well as the opening rooms.
